# Фон личной страницы

Сейчас вкладка называется `toriymi`. После короткой загрузочной заставки появляются заголовок `THE OTHER SIDE` и карточки социальных сетей поверх фона. Нажмите на звезду рядом с `TORIYMI`, чтобы включить ночную тему; выбор сохраняется между посещениями.

Чтобы посмотреть фон, откройте `index.html` в браузере.

- Палитра и градиенты обеих тем настраиваются в `styles.css`.
- В обеих темах фон состоит только из градиентов, без повторяющихся иконок; ночной фавикон находится в `assets/favicon-night.png`.
- Основной фавикон находится в `assets/favicon.svg`.
- Анимация отключается при системной настройке уменьшения движения.
- Cascadia Code подключён локально из `assets/` и используется для текста страницы.
- Ссылки на Telegram, Steam, Last.fm, Spotify и TikTok настроены в `index.html`; карточка Discord отображает имя `toriymi` без ссылки.
- SVG-иконки соцсетей лежат в `assets/icon-*.svg`.
- Ссылки показаны крупными горизонтальными карточками, каждая в отдельном ряду; ширина блока, размер карточек и иконок настраиваются в `styles.css`.

## Музыкальный плеер

Карточка показывает текущий трек Last.fm или последний прослушанный трек профиля `omnipotence88`. Браузер получает данные через обычный Cloudflare Worker по адресу `https://lastfm-now-playing.toriymii.workers.dev/lastfm`; запрос обновляется раз в 30 секунд, Worker кеширует ответ Last.fm на 10 секунд. Last.fm выставляет `nowplaying="true"`, когда подключённый музыкальный сервис передаёт этот статус. [Документация Last.fm](https://www.last.fm/api/show/user.getRecentTracks)

Исходники Worker и его настройки находятся в `lastfm-worker/`. Секрет `LASTFM_API_KEY` хранится в настройках Worker Cloudflare и не включается в сайт или Git. Для локальной разработки укажите его в `lastfm-worker/.dev.vars`; этот файл исключён из Git. [Секреты Cloudflare Workers](https://developers.cloudflare.com/workers/configuration/secrets/)
